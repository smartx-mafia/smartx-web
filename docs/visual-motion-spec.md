# SmartX 官网视觉/动效规范

> 状态：生效中，所有屏幕的精修以本文件为验收标准
> 更新日期：2026-07-20
> 上游：`docs/website-v2-space-narrative-design-intent.md`（叙事结构不变，本文件只约束视觉与动效工艺）

## 1. 发光系统（Glow Budget）

发光是本站最容易廉价化的元素，统一预算：

- **亮度层级**（同屏最多三级）：主角（目标流星/激活轨道节点/当前价格点）> 信号层（其余彩色流星、轨道）> 环境层（星星、微流星、幽灵弧）。
- **脉冲一律走亮度（shader uniform / alpha），禁止对几何做 scale 脉冲**。缩放只允许表达真实的空间运动（接近、远离、拉伸）。
- 光晕半径 ≤ 头部核心尺寸的 4 倍；中心 alpha ≤ 0.35。亮度感靠白核（接近 #fff 的核心），不靠更大的晕。
- 环境层永远不闪不抢：环境流星纯白低亮度、无彩色。

## 2. 流星渲染标准

- **头部**：billboard shader 精灵（白核 + 品牌色晕，指数衰减），脉冲 = `uIntensity` 波动。目标流星在锁定阶段可加十字 glint（shader 内十字光芒项）。
- **尾迹**：连续渐变（宽度与 alpha 沿尾部衰减，近头端向白色偏移），采样密度保证快速滚动时不散点。
- **方向语义**：全站流星共享单一辐射方位（左上 → 右下）；Canvas 2D（首屏）与 WebGL（Universe）必须一致。个体差异只允许弧度、位置、深度。
- **分层**：环境流星（白、细、快、多）铺氛围；信号流星（彩色、亮、慢、少）承担语义。数量上限分开管理。
- **生命周期**：淡出与路径完成绑定——尾迹完整滑出可视区后再回收，不允许在屏幕中央凭空消失。

## 3. 星空标准

- 三层深度旋转（慢/中/快），大星带光晕。
- **闪烁来自少数快闪星**：约 15% 星星使用 0.8–2s 快速闪烁，其余保持 5s+ 慢呼吸；偶发 glint（短暂增亮 + 十字光芒），同屏同时最多 2–3 颗在 glint。

## 4. 遮挡规则（Know the Why）

- 行星是**不透明实体**：核心材质写深度，所有空间对象与它的前后关系必须一致。
- 轨道**双 pass**：前景 pass（depthTest 开，全亮度）只显示行星前方弧段；背景 pass（depthTest 关，alpha ≈ 0.12）作为幽灵弧暗示闭环。
- 节点被行星遮挡时，对应 DOM 标签降到 ~30% 透明度；激活维度的节点标签始终可读（必要时提亮幽灵弧而不是穿透行星）。
- 行星 wireframe 密度不得与轨道抢注意力（icosahedron 细分 ≤ 1）。

## 5. 字体阶梯（全站）

| 角色 | 字体 | 尺寸 | 用途 |
| --- | --- | --- | --- |
| Display | 像素字体 | 48–78px | 仅章节标题（SEE THE MOVE 等）与 Hero 主标题 |
| 面板标题 | UI（Inter 系） | 15–16px semibold | 产品面板、Memory 维度标题 |
| 正文 | UI | 13–14px | 说明文案、证据详情 |
| Kicker / 标签 | UI 大写 | 11px | 章节 kicker、分类标签 |
| 数据读数 | JB Mono | 11–13px | 价格、指标、时间戳 |

- **11px 硬下限**，任何可读文本不得低于。
- 像素字体只出现在 Display 层；产品 UI、Updates、Footer 一律 UI/Mono 字体。
- 每屏最多同时出现三个字级。

## 6. 每屏构图要点

- **Hero**：星空 + 流星雨（含远景微流星层填纵深）；标题居中；信号流星头部脉冲醒目但光晕收敛。
- **See the Move**：标题左中，legend 右上，流星活动区域为上带与中右；吸附静止时流星头保持呼吸脉冲（亮度）。
- **Know the Why**：行星中偏右，四条轨道遮挡关系正确，标签环绕四象限、沿"中心→节点"方向外推；MARKET NODE chip 锚定行星下方。
- **Make the Trade**：图表沿时间轴展示信号事件 pin（证据附着在真实时间点）；右栏为策略卡（触发规则 + 迷你回测 + 跟单入口）+ 下单动作，展示自动化能力（真实/规划中能力，标注状态）。
- **Memory**：字阶严格按 §5；右侧面板与底部导航合并为一套阅读系统；receipt 是从 Trade 延续来的主角对象。

## 7. 验收方式

- 每屏精修完成后用 Playwright 在 1440×900 与 390×844 截图，对照本文件检查发光预算、字阶、遮挡与构图。
- 动效验收必须在前台真实浏览器进行（后台标签页会冻结动画时钟，产生假象）。
